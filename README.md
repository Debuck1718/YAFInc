# YAFInc Website

The official multi-page website for **The Youth and Future Incorporated (YAFInc)** — a Non-Governmental, Non-Profit Organization guided by SDG 3 (Good Health for All) and SDG 4 (Quality Education) to build transformational youth leaders across Ghana and beyond.

**Digital Partner:** [Evantra De Buckman Ventures](https://evantradebuckman.com)

## Structure

- **`index.html`** — Homepage / national mission, campus community, key highlights, and primary calls to action.
- **`about.html`** — Our Story, Vision, Mission, SDG foundations, and core leadership beliefs.
- **`programs.html`** — Leadership & capacity building, life-after-school bootcamps, career guidance, entrepreneurship, and pan-African forums.
- **`impact.html`** — Almost 15-year footprint, 16 regions of Ghana, rural outreach, and community engagement.
- **`stories.html`** — Photographic field journal documenting school visits, village community meetings, and classroom moments.
- **`contact.html`** — Campus mobilization via WhatsApp, organizational partnerships, supporter outreach, and direct contact.
- **`site.css`** & **`site.js`** — Shared styles, active-link routing, responsive navigation, and layout standards.
- **`public/`** — Original field photos from YAFInc community and school outreach.
- **`vercel.json`** — Deployment routing, clean URLs, and static header configuration for Vercel.

## Vercel Deployment Note

In Vercel Project Settings:
- **Framework Preset:** `Other`
- **Root Directory:** `./` (default)
- **Build Command:** leave empty / disabled
- **Output Directory:** leave empty / disabled
